# 美术强化_pass（2026-11-22）

对照概念图（`concept/`）对模型、材质、光照与氛围做了一轮整体强化。玩法、碰撞、寻路、存档与验收逻辑均未改动，模拟层 108 项测试全部通过。本文记录改了什么、怎么看效果，以及性能上需要注意的事。

## 怎么看

```bash
npm install
npm run build && npm run preview   # http://localhost:4173/
```

设置里新增「高画质 / 低画质」两档（默认高）。高画质含泛光、调色、软阴影与扬尘；低画质关闭后期与粒子、降低阴影分辨率，供集成显卡保帧率。

`docs/art-pass/` 下是本轮的实机截图（1080p，开发预设固定机位）。带 `-before` 后缀的是改动前的同机位对照，其余为改动后。重拍命令：

```bash
npm run preview                    # 另起一个终端
node tools/shots.mjs chrome --headless a13-courtyard   # 需本机 Chrome/Edge
```

## 改了什么

材质（MAT-01）整体从 Lambert 转为 PBR（MeshStandardMaterial）。石墙、石板地、发黑木、木地板、灰瓦、碎石六套表面改用 Poly Haven 的 CC0 贴图（颜色 + 法线 + 粗糙度，1k，见 `public/textures/CREDITS.md`），加载前或离线时自动回退到程序化贴图，游戏仍可无外部文件运行。锻铁、破布、残旗、纸张等仍程序化生成，并补了法线细节。贴图按世界尺寸平铺，拼接处连续。

光照与氛围（LGT-01）重做。加了渐变天空穹顶（昼为阴天冷灰、夜为深蓝带月盘与星野）、用同一天空烘出的昼/夜两张环境图做图像照明（IBL），让 PBR 材质有柔和环境光与金属反射。四套照明重新配光以补偿 PBR 的能量守恒。后期管线为渲染 → 泛光 → 调色（饱和、对比、暗部/亮部分色、暗角、细颗粒）→ 输出。火焰改为程序化着色器火舌（不再是圆锥 + 光斑），配火星粒子柱与炉烟；庭院与礼拜堂加了贴地低雾、空气中扬尘、白天高窗光柱。

环境造型（ENV-01…07）细化。墙体加了勒脚与压顶、垛口风化残缺；礼拜堂加了窗花中梃横棂、扶壁压顶、正门罩拱、钟架山墙的小尖塔与十字顶饰；井台加了辘轳绳与吊桶；远景城堡改为带尖顶的轮廓。地表补了概念图里的红叶爬藤、墙脚苔痕、石板缝草丛、积水（低粗糙度反射天空）、枯木与额外瓦砾——这些是清单里原本缺失的 ENV-07 与 VFX-02 项。

角色（CHR-01…03）重塑轮廓。守夜人改为束腰旅行服 + 波浪下摆斗篷 + 深兜帽阴影脸 + 靴子腰带 pouch；灰影改为车削长袍 + 锯齿下摆 + 前倾尖兜帽；黑影改为扭曲躯壳 + 脊背棘刺 + 四肢爪尖。双鬼用菲涅尔边缘自发光在暗背景上勾出轮廓与朝向，衣摆雾改用软烟团贴图。动画状态机不变。

道具补齐。热食碗（PRP-07 原缺）现在备餐后出现在锅旁并冒热气；壁灯加了玻璃罩与铆钉，提灯加了顶 vent。

风格化渲染。调色走青橙分离色调（暗部偏冷青、亮部偏琥珀），配暗角与细颗粒，压低饱和以贴合概念图的低饱和哥特方向；夜景暗部明显偏蓝、火光偏暖，形成冷暖对照。石头与木头的颜色往青灰/发黑方向轻调，统一美术基调。

场景丰富度。庭院原本空旷，补了一批陈设打破单调：木桶 3、断柱与倒落柱头、东墙装饰灯座 2、货箱搭布、额外麻袋、井台垂链，以及散落一地的秋叶（呼应概念图）。这些与爬藤、苔痕、草丛、积水一起让地面和墙脚有了层次。

人物精致化。守夜人加了斜挎包带与挎包、双腰包、围巾、兜帽尖与领口扣、背上毯卷与捆带、靴底绑带、肩甲肘部与手部（不再是圆球手套），车削躯干改为宽肩束腰轮廓，几何分段提高。斗篷下摆波浪更深。双鬼保持菲涅尔边缘光与软烟团，轮廓更清晰。

## 性能

目标仍是 1080p / 60 fps（PRD 第 10 节）。本轮增加了法线贴图、IBL、后期、粒子与陈设，绘制调用从约 145 升到庭院约 280 次、约 3 万三角形（`?preset=dev` 右上角可读）。高档后期在集成显卡上会吃掉原有帧率余量，因此提供低画质档：关闭泛光/调色/扬尘/火星、阴影降到 1024、像素比降到 1。

注意：本轮截图与帧率取样在无头浏览器的软件渲染（SwiftShader）下完成，只能用于前后相对对比，不代表真实显卡表现。请在目标机器（PRD 记录的 Intel UHD / RTX 4060）上用 `node tools/perf.mjs chrome` 与 `node tools/feel.mjs chrome` 重新取样，确认两档画质下的夜间平均帧率与掉帧位置，再决定默认档位。

## 已知取舍

- 双鬼与守夜人仍是程序化几何（无骨骼、无外部模型），风格化轮廓已改善，但交互动画（ANM-01 的 9 条）仍缺，见 PLACEHOLDERS。
- 积水用低粗糙度 + 环境反射近似，不是平面反射或屏幕空间反射，夜里只映出天空与月星。
- 光柱是加性软边面片近似，不是体积散射。
