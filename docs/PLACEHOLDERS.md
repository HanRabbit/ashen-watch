# 占位资源清单

对照 [ART-ASSETS.md](../ART-ASSETS.md) 的编号，记录当前构建里每一项用什么顶替。更新于 2026-11-20。

当前构建不加载任何外部美术或音频文件：没有 GLB 模型、贴图文件和音频采样。所有几何由代码拼装，贴图在画布上生成，声音用 Web Audio 现场合成。下表的「占位」指玩法和辨识度已经可用，但还不是最终资产。

## 关卡模块与场景

| 编号 | 状态 | 现在用的是什么 | 换成正式资产时要补的 |
|---|---|---|---|
| ENV-01 石墙 | 占位 | 按碰撞盒生成的方盒墙加城垛（`src/render/staticLevel.ts`） | 内角、外角、破墙、高窗墙的独立模块；现在没有破墙造型 |
| ENV-02 门洞与尖拱 | 占位 | 挤出成形的尖拱过梁，门框与墙是一体的 | 门框与枢轴分离的独立网格 |
| ENV-03 地面与台阶 | 占位 | 平铺方盒地面；两处矮台阶画成三级，行走高度按斜面计算 | 落差收边模块 |
| ENV-04 顶部结构 | 占位 | 斜置方盒屋面与木梁，礼拜堂西坡留了缺口 | 石拱顶、残瓦顶的造型 |
| ENV-05 礼拜堂地标 | 占位 | 三角山墙、发光的尖拱窗板、空钟架 | 窗花细节 |
| ENV-06 庭院与封门 | 占位 | 圆筒井台加小棚顶，砌死的石拱封门 | 侧廊栏墙现在就是普通墙 |
| ENV-07 远景与覆盖物 | 部分缺失 | 远塔 2、悬崖 2（纯色方盒）、瓦砾 1 堆 | **苔痕、枯木没有做**；瓦砾只有 1 件 |
| ENV-08 场景摆放 | 已完成 | 坐标与交互范围取自 `src/sim/level.ts`，有自动测试核对 | 无 |
| MAT-01 可平铺材质 | 占位 | 画布生成的砌块、木板、噪点贴图（`src/render/materials.ts`），大多是 Lambert 材质 | 6 套 PBR 贴图（法线、粗糙度） |
| LGT-01 照明配置 | 已完成 | 清晨、白天、黄昏、夜间四套，晨曦复用清晨（`src/render/view.ts`） | 换模型后需要重新校一遍曝光 |
