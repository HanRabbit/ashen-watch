# 占位资源清单

对照 [ART-ASSETS.md](../ART-ASSETS.md) 的编号，记录当前构建里每一项用什么顶替。更新于 2026-11-22（美术强化_pass，见 [ART-PASS.md](ART-PASS.md)）。

几何仍由代码拼装，声音用 Web Audio 现场合成。贴图分两类：石、木、地、瓦、碎石六套表面用 Poly Haven 的 CC0 贴图（`public/textures/`，颜色 + 法线 + 粗糙度），离线或加载失败时回退到画布程序化贴图；其余材质程序化生成。没有 GLB 模型与音频采样。下表的「占位」指玩法和辨识度已经可用，但还不是最终资产。
