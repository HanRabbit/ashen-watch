外部影响（仅限这三条，不得再加）：Bloodborne 的哥特建筑语汇；A Plague Tale 的写实材质与光；Dark Souls 的锻铁与破布。

## 1. 艺术定位

**"雨后深秋的哥特要塞，守夜人一盏孤灯对抗黑暗。"**
单一主风格：**写实偏绘画感（Painterly Realism）**——真实尺度、真实材质（PBR + 扫描贴图打底），通过雾、调色和光把画面统一成"油画般的低饱和冷灰 + 琥珀暖光"。

不是：卡通 / 低多边形 / 赛博 / 奇幻发光 / 恐怖血腥 / 高饱和。

## 2. 形体语言

- **建筑**：竖向、尖拱、陡坡屋顶（≥50°）、扶壁、尖塔。石块**有倒角与崩边**，绝无锐利 CG 直角；轮廓线允许轻微不规整（下沉、错位、缺块）。
- **木构**：粗壮方料 + 斜撑 + 铁钉/铁箍，边缘磨圆，端头开裂。
- **锻铁**：卷草（C/S 形卷）、矛尖、铆钉、锤痕；粗细有变化，**不是**均匀圆管。
- **有机物**：爬藤、草、落叶——只在墙脚、石缝、背阴处成簇出现，形成"被遗弃"叙事。
- **鬼**：由**破碎布条**构成，形体向下撕裂、边缘被侵蚀、没有清晰面孔。
- 总体：**风化重、比例写实、结构细节中等密度**；风化是叙事而非噪声。

## 4. 色彩系统（严格；所有新资产的颜色从此派生）

### 4.1 环境中性色（画面 80% 面积）
- 石（干）：冷青灰 `#6b7178` → `#3d4248`；潮湿 `#2a2e33`
- 屋顶石板/瓦：`#3a3f45`，苔斑 `#4b5a3c`
- 木（旧橡）：`#3a2c22`，磨损露出 `#6b5038`
- 锻铁：`#1d1e20`，锈只在边缘/滴水 `#5a3a24`
- 土/泥（缝隙）：`#2b2620`

### 4.2 有机点缀（≤8% 面积，画面唯一的有机暖色）
- 爬藤/落叶：红褐 `#7a2a1c`、酒红 `#5e1a1a`、少量橙黄 `#a8642a`
- 草：枯黄绿 `#6b6a45` → `#4b5a3c`（**不能是鲜绿**）

### 4.3 织物
- 旗/挂毯：褪色酒红 `#5b1f24`；麻布 `#7a6a52`

### 4.4 光色
- 白天天光：冷灰 `#c8d2da`（阴天，**无硬阳光**）
- 月光：冷蓝 `#7f9ccf`
- 火光/灯光：琥珀 `#ffb25e`（2200–2700K）；炉火偏橙 `#ff9a48`
- **冷暖对比是视觉核心**：夜景中每一个暖光源周围都应是冷蓝环境。

### 4.5 角色/阵营
- 守夜人：暗褐/深灰斗篷 `#2f2a26`、皮革 `#4a3a2c`，**提灯是全画面最亮暖点**
- 灰影：灰白破布 `#8d8b86` → `#5a5955`，内部虚空 `#0a0b0d`，兜帽内两点极暗冷光 `#9fb4c8`（≤ 0.3 强度）
- 黑影：近黑灰 `#1e1f22` → `#3a3b3f`，边缘被月光勾出冷灰轮廓，**不发光**

### 4.6 UI
沿用 `src/style.css` 变量：`--stone #1b1e22`、`--text #e4e1d8`、`--dim #a8a69d`、`--amber #f0a84a`、`--cold #9fc0dd`、`--danger #e2735f`。UI 不得引入新色相。

### 4.7 饱和度/亮度规则
- 全局饱和度 0.8–0.92（LUT 后）；任何像素的 HSV 饱和度 > 0.75 只允许出现在火焰核心。
- 白天画面平均亮度 0.40–0.50，天空不过曝（最亮处 < 0.92）；夜晚平均亮度 0.10–0.16，暗部仍可读（墙体轮廓 ≥ 0.06）。
- **禁止**：霓虹、纯饱和色、紫粉、发光符文、绿色/青色光源、随机科幻装饰。

## 5. 材质库（同类材质参数必须一致）

| 类别 | roughness | metalness | 法线强度 | AO | 必须的故事层 |
|---|---|---|---|---|---|
| 石墙（干） | 0.78–0.90 | 0 | 强（1.0–1.5） | 深 | 宏观色差、墙脚潮湿发黑 0–0.8 m、压顶下雨渍竖纹、铁件下锈流 |
| 石墙（湿） | 0.30–0.45 | 0 | 同上 | 同上 | 夜晚整体湿度更高 |
| 石板地面 | 0.70–0.85 | 0 | 强 | 深（缝） | 缝里深色泥 + 枯草、低洼积水、行走路径磨亮 |
| 积水 | 0.02–0.06 | 0 | 雨滴涟漪 | – | 反射天空/灯光；形状不规则，跟随石板低洼 |
| 木（旧橡） | 0.65–0.85 | 0 | 纤维 | 中 | 端头裂纹、边缘磨损露暖褐、铁钉锈晕 |
| 锻铁 | 0.55–0.75 | 1 | 锤痕 | 中 | 边缘锈、凸起处磨亮（roughness 0.4） |

| 玻璃（灯/窗） | 0.10–0.25 | 0 | – | – | 污渍、烟熏、铅条；夜晚灯内火光透出 |
| 布/旗 | 0.92–1.0 + sheen | 0 | 织纹 | 浅 | 褪色、破边、底部潮湿深色 |
| 屋顶瓦 | 0.70–0.85 | 0 | 强 | 深 | 苔斑、屋檐滴水线 |
| 叶/草 | 0.6–0.8，双面 | 0 | – | – | 透光（夜间不透） |
| 鬼（灰影/黑影） | 自定义着色器 | – | – | – | 菲涅尔边缘 + 噪声侵蚀 + 布料飘动；**靠剪影识别，不靠发光** |

- 底层必须是真实贴图（Poly Haven / ambientCG 扫描），程序化噪声只做故事层与去重复，**不得只用噪声**。
- 贴图密度（texel density）：近景 hero ~1024 px/m，中景 ~512 px/m，远景 ≤128 px/m。同一画面同类物体密度一致。
- 外部模型的材质必须重新归一到本表参数（覆盖原模型过亮/过饱和/过光滑的贴图），否则视为风格不符。

## 6. 细节预算（Detail Hierarchy）

| 层级 | 例子 | 几何 | 贴图 | 要求 |
|---|---|---|---|---|
| **Hero** | 守夜人、提灯、两只鬼、壁灯、井、礼拜堂正立面、栅门 | 高（单件 10k–60k 三角） | 2K，完整 PBR + 故事层 | 一级形 + 二级结构 + 三级表面细节齐全；近看不露破绽 |
| **Secondary** | 木桶、木箱、货车、门房家具、钟、火盆、旗、爬藤 | 中（2k–15k） | 1K–2K | 材质质量与 hero 一致，结构简化 |
| **Background** | 庭院墙段、垛口、屋顶、外墙延伸 | 低–中 | 2K 平铺 + 宏观变化 | 轮廓清楚，石块有倒角 |
| **Distant** | 山顶城堡、第二城门、松林、山 | 低 | 无贴图或 ≤512 | 大气简化：被雾分层吞没，对比度 ≤ 近景的 40% |

- 每件资产必须有清楚的：**主体形（一级）/ 结构（二级）/ 表面细节（三级）**。
- 视觉频率一致：相邻物体的细节密度不能相差两个层级（例如扫描级木桶放在方盒墙前 = 违规）。
- 不随机分配细节；细节集中在玩家视线落点（交互物、门洞、光源周围）。

## 7. 光照与渲染

- **白天**：阴天漫射为主（hemi 主导），主光方向左上偏后，阴影柔（半影宽）、强度 0.25–0.45；无硬阳光、无光斑。
- **夜晚**：月光冷蓝为 key（右上，投影），hemi/IBL 保底使场景约 20–30% 可读；暖光源为局部 key；rim 光从月侧轻勾角色轮廓。
- 阴影：VSM/PCSS 式接触硬、远处软；接触阴影（GTAO）必须在墙脚、陈设底、门洞内可见。
- 反射：湿地/积水 SSR（cinematic），其余靠 IBL；反射强度夜晚 > 白天。
- 大气：高度雾 + 距离雾分层，远景被吞没；灯周围有雾内散射光晕；**体积光只用于月光穿云/门洞与室内窗光，不要满屏光柱**。
- 后期顺序（不得增减风格类效果）：HDR → GTAO → SSR → 光晕/散射 → Bloom（阈值高、只给火光）→ ACES 色调映射 → LUT（白天冷灰低饱和 / 夜晚蓝底琥珀高光）→ 暗角 0.45–0.62 → 胶片颗粒 ≤ 0.025。
- 景深：只用于固定机位/过场；游戏视角不加景深。
- 镜头光晕（lens flare）：禁止。色差（chromatic aberration）：禁止。
- 抗锯齿：MSAA ×4 + TAA/SMAA 可选；不得出现可见锯齿或时域鬼影。

## 8. 环境设计

- 叙事："被围困、被遗弃、但仍有人守夜"。每个新增物件必须回答"它为什么在这里"。
- 允许的叙事物：倒塌瓦砾、褪色旗、补过的木箱、蜡油覆盖的烛台、门前沙袋/木桩、钉死的窗、墙上刻痕、乌鸦、湿麻布、旧血迹般的锈痕。
- 有机物分布：墙脚/石缝/背阴成簇，庭院中央开阔区少量；落叶在墙角与井边堆积。
- 层次：每个主要机位都要有前景（墙/桶/藤）、中景（井/栅门）、背景（礼拜堂）、远景（城堡/山）。

## 9. 角色与敌人

- **守夜人**：兜帽 + 及膝斗篷 + 皮革腰带 + 手提六角灯笼；剪影=兜帽+斗篷+提灯。步态沉稳、有重量；转身有惯性；举灯有预备动作。
- **灰影**（concept/04 右）：高瘦、尖兜帽前倾、长袍下摆碎成布条随风飘、袖口下垂；无脸、兜帽内黑暗；身后拖烟。蓄力=抬臂前指 + 布条炸开；退缩=后仰 + 布条收拢冒白烟。
- **黑影**（concept/05）：**四足佝偻的破布体**，长前肢、脊背布条成刺、头部是下垂的兜帽状布团、无明确五官；移动时布条拖尾 + 黑色碎屑粒子。**不要**鹿角、骷髅、细长人形舞者姿态。
- 鬼的材质：漫反射灰阶 + 菲涅尔冷灰边缘 + 噪声侵蚀透明；夜晚可读性来自月光 rim，而非自发光。

## 10. 特效（VFX）

- 风格：写实、克制、低饱和；粒子尺寸小、数量少、生命周期短。
- 火：琥珀核心 → 橙 → 暗红烟；火星向上飘，数量 ≤ 30/火源。
- 烟/雾：冷灰，软粒子（深度淡出），无硬边。
- 鬼：黑烟碎屑（黑影）、灰白布灰（灰影）；被提灯照到冒**白烟**。
- 水：脚踩积水小水花 + 涟漪；雨后滴水（屋檐、井沿）。
- 受击：屏幕边缘暗红暗角脉冲（`#aa1e14` 低透明），无血溅。
- 禁止：彩色魔法粒子、闪光星形、光环符文。

## 11. UI / HUD

- 风格：深石色半透明面板 + 细线描边 + 琥珀强调；衬线字体（Noto Serif SC 系）；无圆角或极小圆角（≤2 px）；无渐变高光、无玻璃拟态。
- 图标：单色线描 / 剪影（`--text` 或 `--amber`），与世界中的锻铁、灯笼造型一致。
- 标题/加载页：用游戏内实际渲染（礼拜堂剪影 + 月夜）或 concept/03 夜景作底，不用不相关的素材。
- HUD 信息层级：状态条（左下）> 目标（左上）> 工具栏（右下）> 提示（中下）。

## 12. 镜头与构图

- 游戏：越肩第三人称，FOV 55°（移动 +3°），临界阻尼跟随，无持续晃动；受击冲击 < 0.15 s。
- 截图/过场固定机位：建立镜头 FOV 60–70°（广角），角色特写 35–45°；三分法，礼拜堂尖塔作为天际线焦点。
- 每个机位必须有前/中/背/远四层。
