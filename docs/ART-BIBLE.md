## 1. 艺术定位

**"雨后深秋的哥特要塞，守夜人一盏孤灯对抗黑暗。"**
单一主风格：**写实偏绘画感（Painterly Realism）**——真实尺度、真实材质（PBR + 扫描贴图打底），通过雾、调色和光把画面统一成"油画般的低饱和冷灰 + 琥珀暖光"。

不是：卡通 / 低多边形 / 赛博 / 奇幻发光 / 恐怖血腥 / 高饱和。

## 2. 形体语言

- **建筑**：竖向、尖拱、陡坡屋顶（≥50°）、扶壁、尖塔。石块**有倒角与崩边**，绝无锐利 CG 直角；轮廓线允许轻微不规整（下沉、错位、缺块）。
- **木构**：粗壮方料 + 斜撑 + 铁钉/铁箍，边缘磨圆，端头开裂。
- **锻铁**：卷草（C/S 形卷）、矛尖、铆钉、锤痕；粗细有变化，**不是**均匀圆管。
- **有机物**：爬藤、草、落叶——只在墙脚、石缝、背阴处成簇出现，形成"被遗弃"叙事。
- **鬼**：由**破碎布条**构成，形体向下撕裂、边缘被侵蚀、没有清晰面孔。
- 总体：**风化重、比例写实、结构细节中等密度**；风化是叙事而非噪声。

## 4. 色彩系统（严格；所有新资产的颜色从此派生）

### 4.1 环境中性色（画面 80% 面积）
- 石（干）：冷青灰 `#6b7178` → `#3d4248`；潮湿 `#2a2e33`
- 屋顶石板/瓦：`#3a3f45`，苔斑 `#4b5a3c`
- 木（旧橡）：`#3a2c22`，磨损露出 `#6b5038`
- 锻铁：`#1d1e20`，锈只在边缘/滴水 `#5a3a24`
- 土/泥（缝隙）：`#2b2620`

### 4.2 有机点缀（≤8% 面积，画面唯一的有机暖色）
- 爬藤/落叶：红褐 `#7a2a1c`、酒红 `#5e1a1a`、少量橙黄 `#a8642a`
- 草：枯黄绿 `#6b6a45` → `#4b5a3c`（**不能是鲜绿**）

### 4.3 织物
- 旗/挂毯：褪色酒红 `#5b1f24`；麻布 `#7a6a52`

### 4.4 光色
- 白天天光：冷灰 `#c8d2da`（阴天，**无硬阳光**）
- 月光：冷蓝 `#7f9ccf`
- 火光/灯光：琥珀 `#ffb25e`（2200–2700K）；炉火偏橙 `#ff9a48`
- **冷暖对比是视觉核心**：夜景中每一个暖光源周围都应是冷蓝环境。

### 4.5 角色/阵营
- 守夜人：暗褐/深灰斗篷 `#2f2a26`、皮革 `#4a3a2c`，**提灯是全画面最亮暖点**
- 灰影：灰白破布 `#8d8b86` → `#5a5955`，内部虚空 `#0a0b0d`，兜帽内两点极暗冷光 `#9fb4c8`（≤ 0.3 强度）
- 黑影：近黑灰 `#1e1f22` → `#3a3b3f`，边缘被月光勾出冷灰轮廓，**不发光**

### 4.6 UI
沿用 `src/style.css` 变量：`--stone #1b1e22`、`--text #e4e1d8`、`--dim #a8a69d`、`--amber #f0a84a`、`--cold #9fc0dd`、`--danger #e2735f`。UI 不得引入新色相。

### 4.7 饱和度/亮度规则
- 全局饱和度 0.8–0.92（LUT 后）；任何像素的 HSV 饱和度 > 0.75 只允许出现在火焰核心。
- 白天画面平均亮度 0.40–0.50，天空不过曝（最亮处 < 0.92）；夜晚平均亮度 0.10–0.16，暗部仍可读（墙体轮廓 ≥ 0.06）。
- **禁止**：霓虹、纯饱和色、紫粉、发光符文、绿色/青色光源、随机科幻装饰。

### 5.1 材质族与区域分配（防单调，v2.1）

2. 平铺用世界空间 UV。墙按段做随机偏移，地面按块做随机偏移或旋转；不得出现可见的重复周期。

### 5.2 使用痕迹与风化（v2.3）

叙事是"被围困、被遗弃、但仍有人守夜"。**痕迹必须讲得出是谁、怎么造成的**，不是均匀撒噪声。每条痕迹都要能回答"它为什么在这里"。

**按成因分四类，每件资产至少覆盖其中两类：**

| 类别 | 具体痕迹 | 出现位置（由成因决定，不得乱放） |
|---|---|---|
| **人用出来的** | 路面磨亮、门槛凹坑、台阶踏面中央下凹与棱角崩缺、门环与门闩周围木头发亮、井沿被绳磨出的凹槽、辘轳摇柄握手处磨光、木箱边角磨圆露白茬、桌沿凳面磨亮 | 只在动线上：主路中线、门洞前后 1 m、台阶、井沿、常摸的把手 |
| **水造成的** | 墙脚 0–0.8 m 潮湿发黑、压顶与窗台下的竖向雨渍、铁件下的锈流、屋檐滴水线、地面积水边缘的深色水痕、井台四周溅湿环、端头木材开裂 | 沿重力方向：一切水平突出物的下方、墙脚、滴水点 |
| **火与烟** | 炉口上方与烟道熏黑、壁灯与火盆上方墙面的烟熏扇形、烛台蜡油堆积、礼拜堂祭台上方顶棚烟灰、灯笼玻璃内侧烟熏 | 只在热源正上方与周边，向上扩散、边缘渐淡 |
| **时间与遗弃** | 苔藓地衣（背阴面、屋面阴沟、墙脚）、石面剥落起壳、灰浆缺失、裂缝、补砌（石色/砌法不同的修补块）、爬藤拔掉后留下的痕、铁件锈斑与铆钉锈晕、鸟粪（压顶与窗台，极克制）、墙角蛛网（极克制） | 背阴、少人走、排水不畅处；补砌集中在坍塌与受力处 |

**强度与密度**
- Hero 资产 ≥3 种可辨认痕迹；Secondary ≥2 种；Background ≥1 种 + 宏观色差。
- 痕迹是**局部**的：单条痕迹覆盖该表面 5%–25%，不得满铺。整面均匀脏 = 违规。
- 磨亮只降 roughness（石 0.70→0.55、木 0.80→0.60、铁凸起 0.55→0.40），**不改色相**；潮湿只压明度并降 roughness 到 0.30–0.45；熏黑压明度但 roughness 保持高。
- 颜色一律留在第 4 节色板内：锈 `#5a3a24`、苔 `#4b5a3c`、潮湿石 `#2a2e33`、泥 `#2b2620`。

**去单调（与 5.1 配合）**
- 同类物件之间要有**实例差异**：每只桶/箱/石块的颜色 ±8%、roughness ±0.06、贴图偏移与旋转向量化随机，避免一眼看出是同一个模型复制。
- 大面积用**混合遮罩**过渡两种材质族（如墙脚石→泥、主路石板→边缘旧石板），不要硬切。
- 同一机位里同一种贴图不得连续覆盖超过 5.1 规定的面积上限。

| **Secondary** | 木桶、木箱、货车、门房家具、钟、火盆、旗、爬藤 | 中（2k–15k） | 1K–2K | 材质质量与 hero 一致，结构简化 |
| **Background** | 庭院墙段、垛口、屋顶、外墙延伸 | 低–中 | 2K 平铺 + 宏观变化 | 轮廓清楚，石块有倒角 |
| **Distant** | 山顶城堡、第二城门、松林、山 | 低 | 无贴图或 ≤512 | 大气简化：被雾分层吞没，对比度 ≤ 近景的 40% |

**Distant 的明度与对比口径（v2.5，实测校准）**

"对比度 ≤ 近景 40%"指的是**整体均值与天空的差**，**不是内部明暗**。把内部也压平会让远景变成一团白、什么都读不出。参考图 concept/03 实测：城堡均值 0.437、**内部标准差 0.178**；森林均值 0.362、标准差 0.153。

| 层 | 均值要求 | **内部标准差** | 说明 |
|---|---|---|---|
| 城堡 | 比天空暗 0.06–0.14 | **≥0.13** | 锥顶/屋面比塔身墙面暗 0.10–0.18，这是"一眼认出是城堡"的关键 |
| 山崖岩体 | 略暗于城堡 | ≥0.08 | 岩层阳面/阴面、节理阴影，不得是光滑锥 |
| 松林 | 比所在坡面暗 0.04–0.10 | ≥0.10 | 树永远暗于背景坡面 |
| 远山剪影带（≥220 m） | 逐层贴近天空（差 ≤0.08/0.06/0.04） | 不设下限 | 这一层就是要融进大气，不要加内部对比 |

- **标准技法**：≥220 m 用**圆柱全景剪影带**（环绕圆柱面 + 顶边多频噪声缓起伏 + 自上而下雾渐变、无光照）；近层 foothill 与城堡山崖保持 3D。庭院仅 20×28 m，远距视差可忽略，任何机位都成立，且 draw calls 降到个位数。
- **fog.color ≠ 天空色**：手动大气混合必须锚定**天空地平线值**，否则 render 改 rig 后明度阶梯会漂移。
- **仰角换算**：7 m 墙 + 1.7 m 相机在约 17 m 外挡住约 19° 仰角以下。远景地形抬升按此计算，脊线仰角需 ~26–31° 才能填满墙头以上天空带；不要拍脑袋定高度。
- 验收除了量均值，**必须量标准差**（`magick <图> -crop WxH+X+Y +repage -format "%[fx:standard_deviation]\n" info:`），并肉眼回答"能否数出城堡有几座塔、看出锥顶是深色的"。数不出来即不合格。

- 每件资产必须有清楚的：**主体形（一级）/ 结构（二级）/ 表面细节（三级）**。
- 视觉频率一致：相邻物体的细节密度不能相差两个层级（例如扫描级木桶放在方盒墙前 = 违规）。
- 不随机分配细节；细节集中在玩家视线落点（交互物、门洞、光源周围）。

## 7. 光照与渲染

- **白天**：阴天漫射为主（hemi 主导），主光方向左上偏后，阴影柔（半影宽）、强度 0.25–0.45；无硬阳光、无光斑。
- **夜晚**：月光冷蓝为 key（右上，投影），hemi/IBL 保底使场景约 20–30% 可读；暖光源为局部 key；rim 光从月侧轻勾角色轮廓。
- 阴影：VSM/PCSS 式接触硬、远处软；接触阴影（GTAO）必须在墙脚、陈设底、门洞内可见。
- 反射：湿地/积水 SSR（cinematic），其余靠 IBL；反射强度夜晚 > 白天。
- 大气：高度雾 + 距离雾分层，远景被吞没；灯周围有雾内散射光晕；**体积光只用于月光穿云/门洞与室内窗光，不要满屏光柱**。
- 后期顺序（不得增减风格类效果）：HDR → GTAO → SSR → 光晕/散射 → Bloom（阈值高、只给火光）→ ACES 色调映射 → LUT（白天冷灰低饱和 / 夜晚蓝底琥珀高光）→ 暗角 0.45–0.62 → 胶片颗粒 ≤ 0.025。
- 景深：只用于固定机位/过场；游戏视角不加景深。
- 镜头光晕（lens flare）：禁止。色差（chromatic aberration）：禁止。
- 抗锯齿：MSAA ×4 + TAA/SMAA 可选；不得出现可见锯齿或时域鬼影。
- 湿石：**石缝与灰浆的 roughness 必须 ≥0.5**，只有石板顶面的低洼积水区才允许 0.02–0.06。把"高度低谷"一律当成积水会让整片地面在夜里变成白色亮网格。
- IBL 环境贴图烘焙**不得包含日盘/月盘**，否则与方向光 key 重复计能，导致镜面过曝。
- 4.7 的"平均亮度"指含天空的全帧均值。阴天深色石材 albedo 下，hemi 允许到约 3.5 才能达到 0.40–0.50。
- 云：**离散积云团**，顶受光、底沉入底色、团间留缝露星；月光银边只勾近月一侧的薄缘，不得整片提亮。白天云隙亮于云顶、云底有形状。角尺度以画面可数 5–10 团为宜，不得退化成水平拉伸的噪声条带。
- 地面亮度校验（白天 ref 机位，显示空间）：地面区块均值 0.28–0.38，最亮处 ≤0.62（积水镜面反射除外）。全帧均值不达标时调天空与曝光，**不得靠提亮地面 albedo 补**。albedo 色值区间（4.1）是硬约束，显示均值是观测值，冲突时以 albedo 为准并上报。

**统一测量口径（v2.6，强制）**：各代理此前各自裁框测"地面均值"，同一场景测出 0.277 与 0.366，数值不可比、导致反复返工。**一律改用共享脚本**：

```bash
/tmp/aw-agents/measure.sh <截图路径> [更多截图...]
```

输出定义（显示空间 sRGB 0..1，灰度）：

| 字段 | 定义 | 目标 |
|---|---|---|
| `frame` | 全帧均值 | 白天 0.40–0.50；夜晚 0.10–0.16 |
| `sky` | 画面上 25% 行均值 | 白天参考 0.55–0.62 |
| `ground` | 画面下 30% 行、**排除 >0.62 的镜面像素**后均值 | 白天 0.28–0.38 |
| `gfrac` | 被排除的镜面像素占比 | 参考值，积水/光池多则偏高 |
| `gstd` | 地面区域标准差（含镜面） | 地面层次，越接近 0 越平 |
| `over` | 全帧 >0.92 像素占比 | 白天 0；夜晚仅月盘/灯芯允许 ≤0.002 |

- 报告里**必须贴该脚本的原始输出**，不要贴自己裁框算的数。
- 局部形体对比（城堡、松林、角色）仍用 `-crop` + `%[fx:standard_deviation]` 单独量，并在报告里写明裁框坐标。
- **白天阴影面可读性**：背光墙面与墙脚陈设的显示亮度不得低于 0.10，否则前景物件在白天变成黑剪影。靠阴天漫射与补光解决，不得靠给资产加自发光。
- **POM 掠射钳制**：共享石材着色器的视差遮挡在极掠射角（视线与墙面夹角 <15°）必须钳制步长与偏移，不得出现整面发黑或撕裂。新构图的左墙常年处于掠射角，这条是硬要求。
- 点光源光池：墙上的暖光池必须是琥珀色且保留石材纹理，**不得过曝成白斑**；强度以"光池中心仍能读出石缝"为准。

## 8. 环境设计

- 叙事："被围困、被遗弃、但仍有人守夜"。每个新增物件必须回答"它为什么在这里"。
- 允许的叙事物：倒塌瓦砾、褪色旗、补过的木箱、蜡油覆盖的烛台、门前沙袋/木桩、钉死的窗、墙上刻痕、乌鸦、湿麻布、旧血迹般的锈痕。
- 有机物分布：墙脚/石缝/背阴成簇，庭院中央开阔区少量；落叶在墙角与井边堆积。
- 层次：每个主要机位都要有前景（墙/桶/藤）、中景（井/栅门）、背景（礼拜堂）、远景（城堡/山）。

## 9. 角色与敌人

- **守夜人**：兜帽 + 及膝斗篷 + 皮革腰带 + 手提六角灯笼；剪影=兜帽+斗篷+提灯。步态沉稳、有重量；转身有惯性；举灯有预备动作。
- **灰影**（concept/04 右）：高瘦、尖兜帽前倾、长袍下摆碎成布条随风飘、袖口下垂；无脸、兜帽内黑暗；身后拖烟。蓄力=抬臂前指 + 布条炸开；退缩=后仰 + 布条收拢冒白烟。
- **黑影**（concept/05）：**四足佝偻的破布体**，长前肢、脊背布条成刺、头部是下垂的兜帽状布团、无明确五官；移动时布条拖尾 + 黑色碎屑粒子。**不要**鹿角、骷髅、细长人形舞者姿态。
- 鬼的材质：漫反射灰阶 + 菲涅尔冷灰边缘 + 噪声侵蚀透明；夜晚可读性来自月光 rim，而非自发光。

## 10. 特效（VFX）

- 风格：写实、克制、低饱和；粒子尺寸小、数量少、生命周期短。
- 火：琥珀核心 → 橙 → 暗红烟；火星向上飘，数量 ≤ 30/火源。
- 烟/雾：冷灰，软粒子（深度淡出），无硬边。
- 鬼：黑烟碎屑（黑影）、灰白布灰（灰影）；被提灯照到冒**白烟**。
- 水：脚踩积水小水花 + 涟漪；雨后滴水（屋檐、井沿）。
- 受击：屏幕边缘暗红暗角脉冲（`#aa1e14` 低透明），无血溅。
- 禁止：彩色魔法粒子、闪光星形、光环符文。

## 11. UI / HUD

- 风格：深石色半透明面板 + 细线描边 + 琥珀强调；衬线字体（Noto Serif SC 系）；无圆角或极小圆角（≤2 px）；无渐变高光、无玻璃拟态。
- 图标：单色线描 / 剪影（`--text` 或 `--amber`），与世界中的锻铁、灯笼造型一致。
- 标题/加载页：用游戏内实际渲染（礼拜堂剪影 + 月夜）或 concept/03 夜景作底，不用不相关的素材。
- HUD 信息层级：状态条（左下）> 目标（左上）> 工具栏（右下）> 提示（中下）。

## 12. 镜头与构图

- 游戏：越肩第三人称，FOV 55°（移动 +3°），临界阻尼跟随，无持续晃动；受击冲击 < 0.15 s。
- 截图/过场固定机位：建立镜头 FOV 60–70°（广角），角色特写 35–45°；三分法，礼拜堂尖塔作为天际线焦点。
- 每个机位必须有前/中/背/远四层。
- **截图规范**：固定机位单次 stage、settle ≥2 s 再拍，玩家站位远离机位（避免镜头缓动穿过斗篷）。交付图**不得为全黑、全白或暗到看不清主体**；出现这类图一律重拍，不得当交付图提交。
